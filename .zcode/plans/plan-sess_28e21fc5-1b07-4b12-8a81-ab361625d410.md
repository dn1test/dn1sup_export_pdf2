## Проблема

На вкладке «📁 Папки и спецификации» папки ведут себя не как требуется: при открытии новой модели автоматически появляются 4 стандартные папки, а удалённые папки «возвращаются» после сохранения/переоткрытия.

## Корневая причина (Ruby, `model/project_data.rb`)

1. `initialize` (строка 213): `@directories = default_directories` — каждая новая модель получает 4 навязанные папки.
2. `normalize_directories!` (строка 968): **если список папок пуст — заново подставляет дефолтные 4 папки**. Вызывается при каждом `apply_payload!` (автосейв) и `load_from_yaml` — поэтому удаление всех папок не сохраняется.
3. `normalize_directories_to_array` (строки 975, 1006): те же откаты к дефолтам при nil/не-массиве.
4. Метод `default_directories` (строки 501–524) больше нигде не используется — удаляется.
5. `config/default_settings.yaml`, секция `directories:` (строки 46–69) — мёртвая конфигурация (код её не читает), вводит в заблуждение — удаляется.

JS-сторона уже соответствует требованиям: пустой список рисует заглушку «Папки проекта не заданы», кнопка «+ Добавить папку» работает, сохранение папок идёт в локальный YAML рядом с .skp (это сохранять и оставляем).

## Изменения

**1. `dn1c_export_pdf2/model/project_data.rb`**
- `initialize`: `@directories = []` (новая модель — без папок).
- `normalize_directories!`: заменить на `@directories = normalize_directories_to_array(@directories)` — пустой список остаётся пустым, Hash из старых YAML конвертируется в массив, дефолты не возвращаются.
- `normalize_directories_to_array`: `nil → []`, else-ветка `→ []` вместо `default_directories`.
- Удалить метод `default_directories`.
- `apply_payload!` (строка 1199): условие `payload[:directories].is_a?(Array)` — чтобы пустой массив от JS гарантированно применялся.

**2. `dn1c_export_pdf2/config/default_settings.yaml`** — удалить секцию `directories:`.

**3. `dn1c_export_pdf2/dialog/html/app.js`** — в обработчике «+ Добавить папку» (строка ~5976): новая папка создаётся с `path: ""` вместо `"!_новые_материалы"` (сейчас новая папка сразу «сканирует» несуществующий путь; реальный путь пользователь выбирает через «📂 Обзор»).

**4. Тесты `dn1c_export_pdf2/test/comprehensive_test.rb`** — добавить проверки: новый `ProjectData` имеет `directories == []`; после удаления всех папок и save/load из YAML список остаётся пустым (дефолты не восстанавливаются).
