## Задача

1. При экспорте дополнительно к верси­онированному PDF (папка артикула, `<Артикул>/pdf/<Артикул>_NN#RRR.pdf` — остаётся как есть) создавать копию **`<имя>.skp` → `<имя>_last.pdf`** рядом с рабочим файлом (перезаписывается при каждом экспорте) и открывать именно `_last.pdf`.
2. В «Истории изменений» автоматически привязывать ссылку на соответствующий верси­онированный PDF и сделать её кликабельной.

Поле `pdf_link` в истории уже существует end-to-end (таблица JS → root `history_edit` YAML → `@history`) — оно нигде не заполняется и не кликабельно. Работаем поверх этого.

## Изменения

### 1. `controller/export_controller.rb` — новый публичный метод
Рядом с `resolve_default_pdf_path` (строка 31):

```ruby
# Путь к «последнему» PDF рядом с рабочим файлом: <dir модели>/<имя>_last.pdf
# nil — если модель не сохранена (копия _last не создаётся)
def resolve_last_pdf_path
  model_path = @model&.respond_to?(:path) ? @model.path.to_s : ""
  return nil if model_path.empty?
  model_dir  = File.dirname(model_path.tr("\\", "/"))
  model_base = File.basename(model_path, ".skp")
  File.join(model_dir, "#{model_base}_last.pdf")
end
```
Плюс `attr_accessor :last_pdf_path` (куда LayoutBuilder положит результат копирования).

### 2. `service/layout_builder.rb` — копия + открытие `_last`
- После успешного `doc.export` и аудита шрифтов (после строки 193), в `begin/rescue` (сбой копии не валит экспорт, `warn` в консоль):
  `last = controller.resolve_last_pdf_path`; если не nil и не совпадает с `pdf_path` — `FileUtils.mkdir_p` + `FileUtils.cp(pdf_path, last)`; сохранить в `controller.last_pdf_path`.
- Шаг 8, автооткрытие (строки 226–229): открывать `controller.last_pdf_path || pdf_path` (тот самый `_last`; при неудаче копии — прежнее поведение). Открытие по-прежнему под гейтом `settings[:auto_open_pdf]`.
- Возвращаемое значение остаётся `pdf_path` (обратная совместимость с тестами).

### 3. `dialog/export_dialog.rb` — привязка pdf_link (`startExport`, ~строка 560)
После успешного `controller.export`:
- Штамп истории: если `project_data.history.first` — Hash с пустым `pdf_link`, записать туда `pdf_file` (версионный путь). Защита «только пустой» — повторный экспорт «без записи правок» не затирает ссылку предыдущей правки (старый версионный файл остаётся в архиве).
- `Model::SessionStore.flush(model)` — сразуpersistить ссылку на диск.
- Передать в JS третий аргумент: `onExportSuccess(pdfPath, newRev, controller.last_pdf_path)`.

Тот же штамп `history.first[:pdf_link]` + flush (меню-экспорт без диалога). Автооткрытие `_last` уже сработает внутри LayoutBuilder.
