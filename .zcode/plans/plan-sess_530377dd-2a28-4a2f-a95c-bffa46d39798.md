## Задача

В шапке диалога экспорта убрать галку 🔒 (блокировка артикула) и кнопку «⚡ Создать». Поле артикула становится нередактируемым. Вместо удалённых элементов — статичный **указатель типа проекта** («🏠 Бытовой» / «💼 Коммерческий»). Сам тип выбирается один раз при открытии панели (существующая модалка «Создать артикул проекта»: 💼 Коммерческий / 🏠 Бытовой / Позже) и больше нигде не меняется. Из карточки «Паспорт объекта» убрать блок «Тип проекта / Назначение» (сегментный переключатель Бытовой/Коммерческий).
