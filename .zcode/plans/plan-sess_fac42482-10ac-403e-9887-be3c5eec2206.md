## Задача

Убрать «Начертание» (`font_weight`) и «Ширина шрифта» (`font_width`) со вкладки **«Настройки»** и перенести эти контролы на тулбар вкладки **«Шаблоны»**, рядом с выбором шрифта. Выбор шрифта (`font_family`) остаётся в обоих местах, как сейчас. Значения начертания/ширины остаются глобальными для документа (хранятся в `pdf_settings` → `settings.yaml`) — меняется только расположение контролов в UI. ID элементов не меняются, поэтому почти вся JS-логика работает без правок.

## Изменения

### 1. `dn1c_export_pdf2/dialog/html/index.html`
- Удалить form-group'ы «Начертание (font_weight)» (строки 483–490) и «Ширина шрифта (font_width)» (строки 492–499) из карточки «Параметры страницы и документа».
- В тулбаре панели шаблонов (`.toolbar-group`, строки 294–304), сразу после блока с `#selectLayoutFontFamily`, добавить два блока `.toolbar-font-control`:
  - метка «Начертание:» + `<select id="selectFontWeight" class="form-control toolbar-select-sm">` с теми же опциями `normal` / `bold` и title-подсказкой (текст старого field-hint перенести в title);
  - метка «Ширина:» + `<select id="selectFontWidth" class="form-control toolbar-select-sm">` с опциями `condensed` / `extra_condensed` и title-подсказкой.
- ID сохраняются → существующие `els.selectFontWeight`, `handleFontWeightChange`/`handleFontWidthChange`, заполнение в `renderUI`, `collectFormData` (`font_weight:`/`font_width:`) и `autoSaveInputIds` в app.js продолжают работать без изменений.

### 2. `dn1c_export_pdf2/dialog/html/app.js`
Правок не требуется (все ссылки идут по неизменным ID). При необходимости — только косметика в подсказках.

### 3. `dn1c_export_pdf2/dialog/html/app.css`
Переиспользуются готовые классы `.toolbar-font-control` / `.toolbar-select-sm`. При необходимости — лёгкая подгонка (например, `max-width` новых селектов), чтобы тулбар не разъезжался.

### 4. `dn1c_export_pdf2/test/comprehensive_test.rb` (секция 4, ~строки 5521–5548)
- Существующие проверки (наличие `id="selectFontWeight"`/`id="selectFontWidth"`, опций `bold`/`extra_condensed`, JS-хендлеров и ключей collectFormData) остаются — проходят без изменений.
- Усилить: селекты начертания/ширины должны находиться внутри toolbar-группы панели шаблонов (рядом с `selectLayoutFontFamily`), а в карточке настроек страницы (регион `fontFamilyGroup` … `chkSaveBackup`) их быть не должно.

### 5. `config/default_settings.yaml`
Без изменений: `font_weight`/`font_width` остаются глобальными ключами настроек, меняется только место контролов в UI.
