# Параметры шаблона: создание параметров вместо готовых списков

## Суть
Готовые каталоги параметров (`PARAM_DEFS`, чек-листы шапки/среднего блока/подвала) полностью удаляются. Вместо них — функция «Создать параметр»: пользователь создаёт параметр, выбирая источник данных из «Данные проекта», «Папки спецификации» (+ группы «Сцена» и «Страница» — по согласованию), и у каждого параметра один и тот же набор настроек размещения: **X, Y (% страницы), выравнивание (лево/центр/право), кегль, цвет, заголовок (текст + вкл/выкл), вкл/выкл**. Блоки «Шапка / Средний блок / Подвал» исчезают; видовое окно (`image_4_3`) и штамп остаются как есть. Миграции старых настроек нет — чистый лист (по согласованию).

## 1. Модель данных
`custom_layouts[tplKey]` = `{ image_4_3: {...}, params: [...] }` (старые `header/slot_1..4/footer` игнорируются при загрузке).

Объект параметра:
```js
{ id: "p_<ts>", source: "project.room_name", label: "Помещение", show_label: true,
  x: 5, y: 2, align: "left", font_size: 10, color: "#0F172A", visible: true }
```
Коробка текста при рендере: align=left → от X до правого края контента; right → от левого края до X; center → центрирована на X (60% ширины). Y — верх текста, многострочный текст растёт вниз.

## 2. Каталог источников (JS, `app.js`)
Новая `buildParamSources(state)` — строится из живых данных, возвращается в модальное окно:
- **Данные проекта**: паспорт объекта (`project.articul/furniture_name/room_name/address/company/description`), заказчик (`customer.id/name/phone/email`), ход работы (`workflow.author/price/start_date/end_date/duration/version/revision/date/last_edit/history/stadia`)
- **Папки спецификации** (динамически по `state.directories`): на каждую папку `dir.<i>.title` («Название — <title>») и `dir.<i>.description` («Спецификация — <title>»)
- **Сцена**: `scene.name`, `scene.description`
- **Страница**: `page.number_total` («Страница N | Всего»), `page.toc` («Содержание — список страниц»)

Удаляются: `PARAM_DEFS`, `buildParamCatalog`, `getInfoLineDef`, `DEFAULT_LINES_BY_CONTENT`, `DEFAULT_HEADER_SLOT`/`DEFAULT_MIDDLE_SLOT` (карты строк), `FIXED_SLOT_DEFS` (шапка/слоты/подвал), `mergePreservedLines`/`hiddenPreservedLines`, мёртвый `getContentLabel`, синтетика футера (`footer_rev_ver_date` и пр.).

## 3. Ruby-резолвер (`service/info_line_resolver.rb`)
Переписать на `resolve_param(context, source)` — таблица источник→значение (сырые значения из `info`/`workflow`/`directories` + `rctx` сцены/страницы). Форматирование как раньше: `v01`, `r001`, «N руб.», метки стадий, история « • », `Страница N | M`, нумерованное содержание. Заголовок больше не из резолвера — берётся из настройки параметра. Старый словарь ключей удаляется.

## 4. Рендер (`service/layout_builder.rb`)
- `render_modular_page`: вместо шагов 2–4 (header/slots/footer) — `render_params` (по одному `add_bounded_text` на параметр: `[label: ]value`, пропуск при пустом значении или `visible: false`).
- Удалить: `render_modular_header`, `render_modular_slots`, `render_modular_slot_card`, `render_modular_footer`, зонную сетку, бакеты футера, `get_block_box` для этих блоков. Сохранить: `render_image_block`, `render_stamp`, `get_page_cfg`, хелперы текста.

## 5. UI (`dialog/html/index.html`, `app.js`, `app.css`)
- Панель «Параметры шаблона»: тулбар шаблона остаётся (шрифт, поля, сброс, бейджи). Вместо трёх карточек — карточка **«Параметры страницы»**: кнопка «+ Создать параметр», список созданных параметров (видимость, источник+заголовок, сводка «X:5 · Y:2 · 10pt», ✎/✕). DnD-сортировка больше не нужна (позиция задаётся координатами).
- Модал «Создать/Редактировать параметр» (`#paramModal`): источник (select с optgroup по группам выше), заголовок (текст + «показывать заголовок»), X (%), Y (%), выравнивание, кегль (select), цвет (палитра+инпут), «Вкл». Автозаголовок = название источника.
- `ensureCustomLayouts`: нормализация к `{ image_4_3, params: [] }`; обработчики `createParam/updateParam/deleteParam` → `updateBlockSlot`-подобный апдейт + `notifyChange()`.

## 6. Дефолты и хранение
- `config/default_layout.yaml`: для каждого типа страницы только `image_4_3` + `params: []`.
- `model/project_data.rb`: `default_custom_layouts` в новой форме; `load_from_layout_yaml`/`save_to_layout_yaml` — нормализация `params` (валидация полей, кламп x/y 0–100), старые ключи отбрасываются. `settings.yaml` не меняется.

## 7. Тесты (`test/test_template_params.rb`)
Переписать под новую модель: позиция/кегль/цвет параметра в RTF и bounds; переключатель заголовка; пустое значение → текст не рисуется; `visible: false`; `scene.name` резолвится по текущей сцене; `page.number_total` = «Страница 2 | 3»; `dir.<i>.description` → «Заголовок: описание»; содержание по включённым сценам; guard-грепы JS (нет `PARAM_DEFS`, есть `buildParamSources`/`paramModal`). Прогон: `ruby -I dn1c_export_pdf2 dn1c_export_pdf2/test/test_template_params.rb` + `comprehensive_test.rb`.
